Square icon-only button for toolbars and topbar actions. Always pass `aria-label`.

```jsx
<IconButton aria-label="Notificações"><Bell size={20} /></IconButton>
<IconButton variant="outline" aria-label="Filtrar"><Filter size={18} /></IconButton>
```

`variant`: `ghost` (default) or `outline`. `active` tints it purple. Sizes `sm`/`md`/`lg`.

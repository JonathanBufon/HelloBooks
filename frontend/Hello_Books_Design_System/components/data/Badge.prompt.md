Pill badge for status. Pick a `tone` by meaning.

```jsx
<Badge tone="success" dot>Disponível</Badge>
<Badge tone="danger" dot>Atrasado</Badge>
<Badge tone="warning">Pendente</Badge>
<Badge tone="primary">Reservado</Badge>
```

Tones: `neutral`, `primary`, `success`, `warning`, `danger`, `info`. See `StatusBadge` for domain-mapped status strings.
